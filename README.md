# Rolsito

AI-Powered Multiplayer RPG Platform. A web-based role-playing game where an AI Dungeon Master guides players through fantastic medieval adventures.

## Vision

Create a platform where players can subscribe, create campaigns, and participate in AI-driven D&D-style adventures. Each campaign has its own independent AI DM instance with persistent memory across sessions.

## Subprojects

1. **Core Engine + AI DM** - Real-time multiplayer game engine with AI DM integration
2. **Characters & Scenarios** - Character creation, stats, inventory, and scenario management
3. **Image Generation** - AI-generated visuals for characters, items, and scenes
4. **Auth & Monetization** - Authentication, subscriptions, payments, and campaign limits

## Tech Stack

- **Frontend:** React + TypeScript
- **Backend:** NestJS (Node.js + TypeScript)
- **Databases:** PostgreSQL + Redis
- **Real-time:** Socket.io (WebSockets)
- **AI:** OpenAI/Anthropic LLMs + Image generation models
